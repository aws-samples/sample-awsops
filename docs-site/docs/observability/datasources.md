# 데이터소스 탐색

연결된 관측성 데이터소스를 각각의 네이티브 쿼리 언어로 읽기 전용 조회할 수 있는 페이지입니다.

<Screenshot src="/screenshots/observability/datasources.png" alt="연동 허브 — 데이터소스 탭" />

## 주요 기능

### 지원 데이터소스와 쿼리 언어
연결된 데이터소스를 그 종류에 맞는 네이티브 언어로 직접 조회합니다. 모든 조회는 **읽기 전용**입니다.

| 데이터소스 | 쿼리 언어 | 예시 |
|-----------|----------|------|
| **Prometheus** | **PromQL** | `rate(node_cpu_seconds_total[5m])` |
| **Mimir** | **PromQL** | `up` |
| **Loki** | **LogQL** | `{job="varlogs"} \|= "error"` |
| **Tempo** | **TraceQL** | `{ duration > 500ms }` |
| **ClickHouse** | **SQL** (읽기 전용) | `SHOW TABLES` |
| **Jaeger** | 서비스 기반 검색 | `service=frontend&limit=20` |
| **Dynatrace** | Metrics v2 metricSelector | `builtin:host.cpu.usage:avg` |
| **Datadog** | 메트릭 쿼리 | `avg:system.cpu.user{*}` |

### 데이터소스 선택
- 드롭다운에서 조회할 데이터소스를 고릅니다. 각 항목에는 **인스턴스 이름**과 **종류(kind)**가 함께 표시됩니다.
- AI 생성은 별도로 수집된 스키마 캐시를 참고합니다. 데이터소스와 타입별 기본 연결은 공유되며 AWS 계정 선택으로 범위가 바뀌지 않습니다.
- 연결 설정과 테스트는 관리자만 수행합니다. 사설 주소는 운영자의 네트워크·DNS 구성이 필요하며, 설정됨과 조회 검증 성공은 다른 상태입니다.
- Timeout은 Prometheus/Mimir/ClickHouse의 서버 실행 제한(기본 10초)과 나머지 종류의 HTTP 응답 제한(기본 12초)을 구분합니다. 저장 값은 1–60초이며 실제 최대 55초를 표시합니다. Mimir API 접두사의 기본값은 `/prometheus`이고 루트 API는 빈 값으로 설정합니다.

### 시간 범위(range) 토글
- 기간 선택기에서 **Prometheus·Mimir**는 즉시 또는 최대 30일, **Loki**는 즉시 또는 최대 7일을 선택합니다.
- **Tempo·Jaeger**는 기본 1시간부터 최대 7일, **Dynatrace·Datadog**는 기본 1시간부터 최대 30일을 조회합니다. 선택한 기간은 실제 검색 요청에 전달됩니다.
- **ClickHouse**의 기간 조건은 SQL에 작성합니다. AI 쿼리 생성은 선택한 조회 기간을 바꾸지 않습니다.

### 결과 표시
- 시계열(matrix/range) 결과는 **시계열 영역 차트**로 그려집니다.
- 단일 시점·로그·트레이스·SQL 결과는 정렬 가능한 **테이블**로 표시됩니다.
- 실제 잘린 결과에는 **결과가 잘렸습니다** 경고가 표시됩니다. 검색 한도에 도달해 완전성을 확인할 수 없는 결과는 **부분 결과**로 표시하며, 확인된 빈 응답에는 **결과 없음**을 안내합니다.
- 미확인·부분 응답은 완료된 빈 결과로 표시하지 않습니다. Jaeger 검색 한도에 도달한 결과도 전체 트레이스 목록을 보장하지 않습니다.

### AI로 쿼리 생성
- 원하는 내용을 자연어로 설명하고 **AI로 생성**을 누르면, 캐시된 스키마를 참고해 해당 언어의 쿼리로 변환되어 입력창에 채워집니다.
- 생성된 쿼리는 **자동으로 실행되지 않습니다.** 검토 후 직접 **실행**을 눌러야 조회됩니다.

## 사용 방법
1. 사이드바에서 **연동**을 클릭한 뒤 **데이터소스** 탭에서 조회할 데이터소스의 **탐색 →** 링크를 엽니다
2. 상단 드롭다운에서 조회할 **데이터소스**를 선택합니다
3. (선택) 기간을 지원하는 데이터소스라면 기간 선택기에서 조회 범위를 고릅니다
4. 입력창에 해당 언어의 쿼리를 직접 입력하거나, 자연어 설명 후 **AI로 생성**으로 쿼리를 채웁니다
5. 쿼리를 검토한 뒤 **실행**(또는 입력창에서 **Enter**)을 눌러 조회합니다
6. 차트 또는 테이블로 나타난 결과를 확인합니다

:::info 데이터소스가 없을 때
연결된 데이터소스가 하나도 없으면 드롭다운이 비어 있고 **"설정된 데이터소스가 없습니다 — Datasources 탭에서 추가하세요."** 안내가 표시됩니다. 데이터소스 연결과 자격 증명 등록은 **연동(Integrations) 허브**(`/integrations` → 데이터소스 탭)에서 진행합니다.
:::

:::tip 빠른 실행
입력창에서 **Enter**를 누르면 바로 실행됩니다. 자연어 설명창에서 **Enter**를 누르면 **AI로 생성**이 실행됩니다.
:::

:::tip 결과가 잘렸다면
**결과가 잘렸습니다(상한 도달)** 경고가 보이면 쿼리 범위나 조건을 좁혀 다시 조회하세요.
:::

## AI 분석 팁
- "지난 5분간 모든 노드의 CPU 사용률" → PromQL 쿼리로 생성
- "error 를 포함하는 최근 로그" → LogQL 쿼리로 생성
- "500ms 이상 걸린 트레이스" → TraceQL 쿼리로 생성
- "테이블별 행 수" → 읽기 전용 SQL 로 생성

## AI로 진단

Datasources 관리 탭에서 각 kind의 **default** 데이터소스 행에는 **AI로 진단** 링크가 표시됩니다
(지원 kind: Prometheus·ClickHouse·Loki·Mimir·Tempo). 클릭하면 AI 어시스턴트로 이동하며, 섹션이
고정된 진단 프롬프트가 입력창에 미리 채워집니다(Prometheus/ClickHouse → `/observability`,
Loki/Mimir/Tempo → `/monitoring`). **자동으로 전송되지 않으며**, 검토 후 직접 전송하면 새 대화로
시작됩니다. 에이전트는 해당 커넥터의 쿼리/스키마 도구로 데이터소스 응답 상태를 점검합니다.

## Explore 기능 요약

- 타입별 **예제 쿼리·자연어 프롬프트 칩**(8개 kind), 클릭 시 즉시 실행/입력
- **7d/30d 기간 프리셋**(Prometheus/Mimir 30d, Loki 7d — kind별 상한)
- 결과 **메타데이터 바**(행/시리즈 수 · 왕복 ms · 쿼리 언어 · 형태)
- **Loki 전용 로그 뷰어**(최신순 정렬·라벨 배지), Tempo/Jaeger **duration 바**
- AI 생성 쿼리 **출처 배너**, 관리 탭 **KPI 타일·새로고침**
