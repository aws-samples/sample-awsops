这是一个大型发布，将外部可观测性栈作为数据源对接，并新增了**将自然语言转换为查询**的功能和 **15 部分 AI 综合诊断**报告。

<!--truncate-->

:::tip 核心变化
**7 种可观测性集成** · **自然语言 → PromQL/LogQL/TraceQL/SQL** · **AI 路由 10→11（`datasource`）** · **15 部分综合诊断 + DOCX/PDF/调度** · **SSRF 防范**
:::

## 外部可观测性集成（7 种）

在 AWS 数据之外，还可将现有可观测性平台作为数据源对接。

| 类别 | 平台 |
|------|--------|
| Metrics | Prometheus · Dynatrace · Datadog |
| Logs | Loki · ClickHouse |
| Traces | Tempo · Jaeger |

- `/datasources` — 数据源 CRUD · 连接测试 · 认证配置
- `/datasources/explore` — 直接执行查询 + **AI 查询生成（自然语言 → PromQL/LogQL/TraceQL/SQL）**
- AI 助手的 `datasource` 路由会自动分类外部指标相关问题（AI 路由从 **10 → 11** 扩展）

## AI 综合诊断（15 部分）

- Bedrock Opus 自动将整个基础设施分析为 **15 个部分** — 以成本/安全/稳定性为核心
- **DOCX · Markdown · 浏览器 Print-to-PDF** 导出
- **每周/双周/每月**自动调度（report scheduler）
- 打印用报告页面 `/ai-diagnosis/report`（A4 分页）

## 安全（SSRF 防范）

- `datasource-client.ts` 的 URL 验证保护包括 AI 路由在内的所有外部 fetch 路径
- 基于 allowlist 的私有网络访问控制 + IPv6 私有/链路本地（`fc00::/7`、`fe80::/10`）检测
- 数据源查询和 AI 查询生成仅限管理员使用

## 其他

- 多路由合成引入 **Converse Stream API** + AgentCore 响应打字效果
- 自动清理僵尸 PostgreSQL 连接，通过监控查询时间范围过滤防止 pg pool 耗尽
- EKS Access Entry 状态显示 + kubeconfig 注册、EKS 服务资源标签页
