我们发布了**在全新架构之上从零重建的 AWSops v2.0.0**。单台 EC2 单体应用被重构为**基于 Terraform 的 MSA**，并在其之上重新打造了 AI 助手、AI 诊断、拓扑、EKS、成本等几乎所有页面。从用户角度看，从专属域名、应用内登录到主题、移动端，整体体验焕然一新。

<!--truncate-->

:::tip 核心变化
**Terraform MSA 转型（ECS Fargate + Aurora）** · **私有边缘 + 应用内登录（RS256）** · **流式 AI 助手（领域自动路由·线程持久化）** · **AI 诊断报告（深度可选 · MD/DOCX/PDF）** · **请求流拓扑图** · **EKS 集群舰队 + 集群内查询** · **3 种主题 + 移动端响应式**
:::

## 新架构（全面重建）

我们解构了 v1 的单台 EC2 主机（构建、运维、本地状态全部耦合在一起的架构），重新设计为可独立部署、独立扩展各组件的架构。

| 领域 | 内容 |
|------|------|
| **IaC** | CDK → **Terraform**（S3 backend） |
| **计算** | 单台 EC2 → **ECS Fargate**（web/worker 分离，arm64） |
| **数据** | 本地状态 → **Aurora Serverless v2（PostgreSQL 17）** 持久化 |
| **边缘** | 公开 ALB → **CloudFront VPC Origin → 内部 ALB → Fargate**（无公开 ALB，TLS 端到端） |
| **认证** | 边缘仅校验 exp → **Cognito + Lambda@Edge RS256 JWKS 验证** |
| **长时任务** | 进程内执行 → **异步 Worker 层**（SQS + Step Functions + Lambda/Fargate） |
| **路径** | `/awsops` 前缀 → **根路径（`/`）**，专属域名 |

## 焕新的体验

- **应用内登录** — 在自有 `/login` 表单中使用邮箱·密码登录。未认证的请求会在边缘被引导至登录页面。
- **3 种主题** — **Cobalt（默认）· Teal · Dark** 主题选择器。选择会被保存，图表和品牌标识也会随主题变化。
- **移动端响应式** — 通过顶部栏 + 底部 5 个标签 + 滑出式抽屉，在窄屏上也能使用全部功能。
- **命令面板** — 通过 `Cmd-K`（或 `Ctrl-K`）直达任意页面·资源，并可切换主题。

## AI — 更快、更聪明

- **AI 助手** — 以令牌为单位**流式输出**回答，并以 **Markdown（表格·代码·列表）**呈现。问题会**自动路由到相应领域（网络·成本·安全等）**，对话**持久化保存**，抽屉与全屏视图共享同一份记录。
- **AI 诊断** — 以 **Light / Mid / Deep** 深度生成账户运维状态综合报告，并可导出为 **MD · DOCX · PDF**。同时提供意图与实际的（不变式）核对，以及与上一份报告对比的变化洞察。

## 更广的可见性

- **拓扑** — 由 Route53 → CloudFront → LB → Target Group → 目标构成的**请求流图**。点击节点可进入聚焦模式 + 详情面板（复制 ARN·向 AI 提问）。
- **资源库存** — 对 EC2·Lambda·RDS·S3·VPC·IAM 等 **20 多种**资源进行排序·搜索·详情查看。
- **EKS / Kubernetes** — 集群**舰队摘要**与节点·Pod·Deployment 的**集群内查询**（只读），以及 OpenCost 安装指南。
- **成本** — 按服务的成本分解·下钻、月末预测，以及 **Bedrock 模型使用量**（令牌·延迟·成本·缓存节省）。
- **数据源探索** — 以**原生查询语言（PromQL/LogQL/TraceQL/SQL）**只读查询已连接的可观测性数据源。

## 只读运维姿态

AWSops 专注于**观察·分析·诊断**运维状况，**不会变更 AWS 资源。**对于需要安装·变更的操作，我们提供脚本和指南，供用户自行执行。
