# 登录

本页面可使用电子邮件和密码登录 AWSops。

<Screenshot src="/screenshots/getting-started/login.png" alt="登录界面" />

## 主要功能
### 登录表单
- **电子邮件**：输入分配给您的电子邮件地址。
- **密码**：输入密码。
- **保持登录**：勾选后，即使关闭浏览器再重新打开，会话也会保持。在公用电脑上请取消勾选。
- **登录 →**：使用输入的凭证尝试登录的按钮。

### 自动重定向
- 在未登录状态下访问任何页面时，会自动跳转到**登录**界面。
- 登录成功后会立即跳转到仪表板（或原本要访问的页面）。

### 错误提示
- 错误的电子邮件·密码、需要额外验证的账户、临时的服务错误会以表单内的**内联通知**显示。

## 使用方法
1. 在浏览器中访问 AWSops 地址。如果尚未登录，会出现**登录**界面。
2. 输入**电子邮件**和**密码**。
3. 若要保持会话，请让**保持登录**处于勾选状态。
4. 点击**登录 →** 按钮。
5. 认证完成后跳转到仪表板。
6. 若要登出，点击左侧边栏底部我的账户旁边的**登出图标**。会话将被清理，并返回**登录**界面。

## 使用技巧
:::tip 保持登录
勾选**保持登录**后，下次访问时无需再次登录。在公用·共享设备上请取消勾选，并在使用后务必登出。
:::

:::info 无法登录时
表单上方会显示内联通知。请重新检查电子邮件·密码；如果持续失败，请稍后重试或联系管理员。
:::
