# AI 助手

这是一个用自然语言提出 AWS·Kubernetes 运维问题并获得 AI 回答的全屏聊天页面。

<Screenshot src="/screenshots/overview/assistant.png" alt="AI 助手 — 推荐问题" />

## 主要功能

### 自然语言提问与流式回答
- 用平时说话的方式提问，回答会**按 token 实时流式呈现**。
- 回答以 **Markdown** 渲染，表格、代码块、列表都会美观地显示。
- 对 AWS 资源仅进行**只读**查询·分析，不会更改资源。

<Screenshot src="/screenshots/overview/assistant-answer.png" alt="AI 助手回答（领域徽章 + Markdown 表格）" />

### 自动领域路由
- 问题会被**自动分类**到最合适的领域（**Network** · **Data** · **Security** · **Cost** · **Monitoring**）。
- 通过回答中显示的**彩色领域徽章**（例：💰 **Cost**）可以确认是哪个领域给出的回答。
- 回答结束后会提示最多 2 个**相关领域标签片**，可将同一问题再次发送到其他领域。

### 对话列表（左侧栏）
- 已保存的对话按**最新顺序**堆叠在左侧栏中。
- 点击对话可以重新打开，将鼠标悬停在条目上会出现**删除**按钮。
- 通过**新对话**按钮开始一个空白对话。
- 对话会自动保存，并与可在任意页面打开的**浮动聊天窗口共享同一记录**。

## 使用方法
1. 在侧边栏点击**助手**，或在任意页面打开浮动聊天按钮。
2. 点击初始界面的**推荐问题标签片**（例：*本月成本趋势*、*两个资源间通信问题的原因*、*IAM 过度权限检查*、*最近告警摘要*）之一，或直接输入。
3. 在回答流式呈现的过程中，通过**领域徽章**确认由哪个领域在处理。
4. 点击回答下方的**相关领域标签片**，将同一问题在其他领域再问一次。
5. 在左侧栏点击之前的对话重新打开，或通过**新对话**开始新的主题。

## 使用技巧

:::tip 发送到特定领域
在消息最前面加上 **`/`**，可以将该条消息发送到特定领域（例：`/network 确认两个子网间的通信`）。部分领域仍显示为**准备中**。
:::

:::info 与浮动聊天共享同一记录
本页面的对话与浮动聊天窗口使用**同一记录**。如果特定对话的链接末尾带有 `?thread=<id>`，会直接打开该对话。
:::

:::info 时间显示
屏幕上显示的时间以韩国标准时间（KST, Asia/Seoul）为准。
:::
