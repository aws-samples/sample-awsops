# AI 诊断

此页面可基于 AWS 原生数据生成并查看分析账户整体运维状态的综合诊断报告。

<Screenshot src="/screenshots/operations/ai-diagnosis.png" alt="AI 诊断报告" />

## 主要功能

### 执行诊断
- **诊断深度（Tier）**：选择分析范围。
  - **Light**：仅快速检查核心项目（当前目录·令牌预算与 Mid 相同）
  - **Mid**：均衡的标准诊断（默认值）
  - **Deep**：广泛分析 15+1 个章节（共 16 渲染）。仅 **Deep** 可额外选择使用的模型（**Sonnet** / **Opus**），选择 **Opus** 时会一并显示费用提示。
- 点击**执行诊断**按钮后，报告将在后台异步生成。

### 进度显示
- 生成过程中，进度条会实时显示**数据收集 → 章节分析 → 报告组装**各阶段。
- 完成后报告会自动打开。

### 报告列表
左侧边栏列出最近的报告：
- 自动生成的**标题**、**id**、**诊断深度（Tier）**、**模型**、**状态（status）**、**生成日期**（KST）

### 报告正文
- 正文以 **Markdown** 渲染，并附带**目录（TOC）**。
- 通过顶部按钮可以导出为 **MD / DOCX / PDF** 格式。

### 洞察徽章
- **意图与实际对比 / 变化洞察**徽章行汇总不变式（invariant）违规以及与上一份报告相比的变化。
- 在**意图不变式候选**（Intent）面板中可以提议、接受、拒绝候选项。（仅限管理员，对其他用户为只读）

### 标题 · 标签 · 删除
- 报告作者或管理员可以内联修改**标题**、添加或删除**标签**，以及**软删除**报告。

## 使用方法

1. 在侧边栏点击 **AI 诊断**。
2. 选择**诊断深度**（**Light** / **Mid** / **Deep**）。
3. 如果选择了 **Deep**，可按需指定模型（**Sonnet** / **Opus**）。
4. 点击**执行诊断**按钮开始生成。
5. 通过进度条确认各阶段，完成后查看自动打开的报告。
6. 通过正文左侧的**目录**在章节间移动，并在顶部导出为 **MD / DOCX / PDF**。
7. 如有需要，可编辑**标题**、**标签**或删除报告。（在拥有权限的情况下）

## 使用技巧

:::tip 防止重复执行
以相同条件（深度·模型）在一小时内再次执行时，不会重新生成，而是返回既有报告并显示重复执行提示。
:::

:::info 权限说明
**修改标题·标签·删除**仅限报告作者或管理员。**意图不变式候选**的提议、接受、拒绝仅限管理员，其他用户尝试时会被服务器拒绝。
:::

:::info 只读分析
AI 诊断仅观察和分析 AWS 资源，不会进行变更。报告仅用于提供分析结果。
:::

## AI 分析技巧

查看报告后，可以通过浮动按钮或 **AI 助手**页面继续提出后续问题：

- "本次诊断中最危险的项目是什么？"
- "与上一份报告相比有哪些变化？"
- "请解释所显示的不变式违规的原因。"
