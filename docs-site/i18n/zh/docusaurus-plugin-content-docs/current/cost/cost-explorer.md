# Cost Explorer

此页面可分析本月累计费用与各服务的费用分布。

<Screenshot src="/screenshots/cost/cost-explorer.png" alt="Cost Explorer" />

## 主要功能

### 核心指标卡片
页面顶部的 7 个指标卡片汇总费用现状：
- **本月累计**：从本月 1 日到当前为止的累计费用
- **环比（MoM · 日均）**：与上月相比的增减率。由于本月仍在进行中，按**日均**为基准比较，以减少部分汇总造成的失真
- **预计月末费用**：AWS 预测值或线性估算值（卡片底部显示 **AWS 预测** / **线性估算**）
- **日均**：最近 30 天日合计的平均值（不含今天仍在累计的桶；应用服务筛选）
- **上月总额**：上一个月的总费用
- **服务数量**：产生费用的服务个数 — 若有服务较上月增长超过 20%，显示 'N 个增长 >20%' 子文本
- **最大服务**：产生费用最多的服务及其金额

若完全没有数据（所有序列为空），会显示“所选期间没有成本数据”横幅并提供**检查可用性**按钮 — 若确认 Cost Explorer 未启用（主机账户），显示启用引导（在 Billing 控制台启用，数据显示最长需 24 小时）；若确认可用，则提示该期间很可能没有产生费用。

### 趋势图表
- **月度费用趋势**：以面积图显示最近约 6 个月的月度费用
- **每日费用趋势**：以面积图显示最近约 30 天的每日费用

### 各服务分布
- **各服务费用**：以横向条形列表显示各服务的费用
- **费用构成**：以环形图显示排名靠前的服务，其余归入**其他**项
- **服务详情表格**：服务 / 本月 / 上月 / 变化率（日均归一化 — 阈值配色：>20% 红 · >0 橙 · <0 绿；无基准月 '—'）/ 占比（迷你条）— 支持数字排序、搜索、仅问题切换

### 服务下钻面板
在表格中点击服务行，右侧会打开详情面板：
- **每日费用趋势（30 天）**：该服务最近 30 天的每日费用
- **使用类型分解**：最近 3 个月按使用类型（Usage Type）的费用分解
- 拖动面板边界可调节宽度，通过 **×** 按钮、**Esc** 或点击外部区域关闭

<Screenshot src="/screenshots/cost/cost-drilldown.png" alt="服务下钻面板" />

## 使用方法

1. 在侧边栏点击**费用**
2. 通过顶部指标卡片确认本月累计费用和月末预估值
3. 通过趋势图表掌握月度和每日的费用走向
4. 通过**各服务费用**列表和**费用构成**环形图确认费用分布
5. 在**服务详情**表格中点击行，查看该服务的每日趋势和使用类型分解
6. 通过刷新按钮重新加载最新数据

## 使用技巧

:::tip 理解部分汇总
由于本月仍在进行中，**环比**指标不是按整月合计，而是按**日均**为基准比较。因此在月初、月中也能显示可信的增减率。
:::

:::info 部分失败时的行为
即使部分趋势、月度、预测数据加载失败，各服务分布仍会正常显示。如果看不到费用数据，请检查 Cost Explorer 权限或会话状态。
:::

:::info 时间表示
屏幕上显示的时刻以韩国标准时间（KST, Asia/Seoul）为准。
:::

## AI 分析技巧

通过浮动按钮的 AI Assistant 或 Assistant 页面可以提出如下问题：
- "本月费用最多的服务是什么？"
- "与上月相比，费用是增加了还是减少了？"
- "告诉我月末预计费用"
- "帮我按 EC2 使用类型分解费用"
