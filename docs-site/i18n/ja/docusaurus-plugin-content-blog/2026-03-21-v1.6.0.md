## 多言語対応 (i18n)

React Context + localStorage ベースで、URL ルーティングなしに言語を切り替えます。Next.js の `basePath: '/awsops'` と衝突しない設計です。

<I18nArchitecture />

| 項目 | Before (v1.5) | After (v1.6.0) |
|------|---------------|-----------------|
| 言語 | 韓国語のみ | 韓国語 + 英語 |
| 翻訳キー | 0 | **500+** (各言語) |
| 言語切り替え | なし | Sidebar の EN/한 トグルボタン |
| AI 応答言語 | 韓国語のみ | 設定に応じて韓/英を自動切り替え |
| URL 変更 | - | なし (basePath 衝突を防止) |

:::info なぜ URL ベースの i18n を使用しないのか?
Next.js の `basePath: '/awsops'` が設定されているため、Next.js 組み込み i18n の locale prefix(`/ko/awsops`、`/en/awsops`)と衝突します。React Context + localStorage 方式は URL を変更しないため、この問題を回避します。
:::

**翻訳範囲**:
- 全 35 ページのテキスト
- Header、Sidebar メニューラベル
- AI ステータスメッセージ (分析中、Gateway 接続中、完了 など)
- DataTable カラムヘッダー
- StatsCard ラベル

## Bedrock モニタリング (`/bedrock`)

Bedrock モデル別使用量を CloudWatch メトリクスと AWSops アプリ自体のトークン追跡でモニタリングします。

<BedrockMetricsFlow />

| 機能 | 説明 |
|------|------|
| **モデル別使用量** | Claude Sonnet、Opus などモデル別の呼び出し数/トークン |
| **Account vs AWSops** | AWS アカウント全体の Bedrock 使用量に対する AWSops アプリの比率 |
| **AI トークンコスト** | チャット応答に入力/出力トークン数 + USD コストを表示 |
| **プロンプトキャッシング** | キャッシュヒット率の表示、コスト削減効果の確認 |
| **デフォルト範囲** | 7 日 (変更可能) |
| **API ルート** | `/api/bedrock-metrics` (`src/app/api/bedrock-metrics/route.ts`) |

:::tip AI トークンコスト表示
チャット応答の下部に `入力: 2,450 トークン · 出力: 1,200 トークン · $0.0234` の形式でコストを表示します。
ユーザーが各質問のコストをリアルタイムで確認できるため、コスト意識が高まります。
:::
