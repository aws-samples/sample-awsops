## AgentCore ダッシュボード (`/agentcore`)

Bedrock AgentCore Runtime と 8 つの Gateway のステータスを一目で把握できる専用ダッシュボードです。

<AgentCoreDashboardView />

- **Runtime ステータス**: `data/config.json` の `agentRuntimeArn` でステータスを照会
- **8 Gateway カード**: 各 Gateway のステータス、ツール数、主要機能を表示
- **125 ツールの全一覧**: 検索、Gateway 別フィルターに対応
- **アーキテクチャ図**: Runtime → Gateway → Lambda の関係を可視化

:::info API エンドポイント
`/api/agentcore` (`src/app/api/agentcore/route.ts`) は `data/config.json` から ARN を読み取り、AWS API でステータスを照会します。ハードコーディングされたアカウント情報がないため、config を変更するだけでどの環境でも動作します。
:::

## Sign Out 機能

Header にログアウトボタンを追加し、Cognito セッションを安全に終了します。

| 項目 | Before | After |
|------|--------|-------|
| ログアウト | 不可能 (ブラウザを閉じるのみ) | Header のログアウトボタン |
| クッキー削除 | `document.cookie` (HttpOnly にアクセス不可) | `POST /api/auth` サーバーサイド削除 |
| 認証状態 | ブラウザキャッシュに依存 | Cognito 再認証を強制 |

:::warning HttpOnly クッキーの削除
`document.cookie` では HttpOnly クッキーを削除できません。
必ず**サーバーサイド API** (`src/app/api/auth/route.ts`) を通じて `Set-Cookie: token=; Max-Age=0` を返す必要があります。
:::

## CloudWatch メトリクステーブル (4 サービス)

4 つのサービスに対して専用 API ルートと CloudWatch メトリクステーブルを追加しました。すべて同一パターン(`cloudwatch get-metric-data` → プログレスバー + 数値)を使用します。

<CloudWatchMetricsFlow />

| サービス | API ルート | メトリクス |
|--------|-----------|--------|
| **MSK** | `/api/msk` | ブローカー別 CPU、Memory、BytesIn、BytesOut |
| **RDS** | `/api/rds` | インスタンス別 CPU、Memory、Connections、IOPS |
| **ElastiCache** | `/api/elasticache` | ノード別 CPU、Memory、Network、Connections + Valkey エンジンカード |
| **OpenSearch** | `/api/opensearch` | ドメイン別 CPU、JVM Memory、Cluster Status、Search Rate |

## Resource Inventory (PR #1)

`/inventory` ページで 18 種のリソース数量推移をモニタリングします。

- **マルチラインチャート**: リソース別数量変化の時系列
- **コスト影響の推定**: リソース変化に応じた予想コストを表示
- **`src/lib/resource-inventory.ts`**: スナップショットベース (`data/inventory/`)、追加クエリ 0 件
- **Cost Explorer 可用性**: `checkCostAvailability()` で MSP Payer を自動判別
