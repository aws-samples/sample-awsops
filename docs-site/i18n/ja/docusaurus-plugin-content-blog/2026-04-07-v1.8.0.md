外部オブザーバビリティスタックをデータソースとして連携し、**自然言語をクエリに変換**する機能と **15 セクション AI 総合診断**レポートを追加した大型リリースです。

<!--truncate-->

:::tip 主な変更点
**7 種オブザーバビリティ連携** · **自然言語 → PromQL/LogQL/TraceQL/SQL** · **AI ルーティング 10→11（`datasource`）** · **15 セクション総合診断 + DOCX/PDF/スケジュール** · **SSRF 防止**
:::

## 外部オブザーバビリティ統合（7 種）

AWS データに加えて、既存のオブザーバビリティプラットフォームをデータソースとして連携します。

| 種類 | プラットフォーム |
|------|--------|
| Metrics | Prometheus · Dynatrace · Datadog |
| Logs | Loki · ClickHouse |
| Traces | Tempo · Jaeger |

- `/datasources` — データソース CRUD · 接続テスト · 認証設定
- `/datasources/explore` — 直接クエリ実行 + **AI クエリ生成（自然言語 → PromQL/LogQL/TraceQL/SQL）**
- AI アシスタントの `datasource` ルートが外部メトリクスの質問を自動分類（AI ルーティングを **10 → 11** に拡張）

## AI 総合診断（15 セクション）

- Bedrock Opus がインフラ全体を **15 セクション**で自動分析 — コスト/セキュリティ/信頼性を中心に
- **DOCX · Markdown · ブラウザ Print-to-PDF** エクスポート
- **週次/隔週/月次**の自動スケジュール（report scheduler）
- 印刷用レポートページ `/ai-diagnosis/report`（A4 ページブレーク）

## セキュリティ（SSRF 防止）

- `datasource-client.ts` の URL 検証が、AI ルートを含むすべての外部 fetch 経路を保護
- allowlist ベースのプライベートネットワークアクセス制御 + IPv6 プライベート/リンクローカル（`fc00::/7`、`fe80::/10`）の検知
- データソースクエリ・AI クエリ生成は管理者専用

## その他

- マルチルート合成に **Converse Stream API** + AgentCore 応答のタイピング効果
- ゾンビ PostgreSQL コネクションの自動クリーンアップ、モニタリングクエリの時間範囲フィルターで pg pool 枯渇を防止
- EKS Access Entry の状態表示 + kubeconfig 登録、EKS サービスリソースタブ
