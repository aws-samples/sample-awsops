# 非同期ジョブ

レポート生成のような重く時間のかかる作業をバックグラウンドワーカーが処理した実行履歴を照会できるページです。

<Screenshot src="/screenshots/operations/jobs.png" alt="非同期ジョブ一覧" />

## 主な機能
### ジョブ一覧テーブル
直近のジョブを最大 50 件表示します。重い作業は画面上で即時実行されず、バックグラウンドワーカーに引き渡されます。このページはその処理結果を**読み取り専用**で表示します。

| カラム | 説明 |
|------|------|
| **Type** | ジョブの種類 |
| **Status** | 処理状態。色付きバッジで表示されます |
| **Runtime** | ジョブが実行された場所 |
| **Error** | 失敗時のエラーメッセージ |
| **Created** | ジョブが作成された時刻（KST） |

### Status バッジ
- **queued**: キューに登録され、処理を待っている状態
- **running**: ワーカーが処理中の状態
- **succeeded**: 正常に完了した状態
- **failed**: 処理中に失敗した状態（Error カラムで原因を確認できます）
- **canceled**: キャンセルされた状態

### Runtime
- **lambda**: 短時間で終わるジョブを処理した実行環境
- **fargate**: 長時間またはメモリを多く使うジョブを処理した実行環境

## 使い方
1. サイドバーで**ジョブ**をクリックします
2. テーブルで最近のジョブの **Status** と **Runtime** バッジを確認します
3. カラムヘッダーをクリックして希望する基準でソートします
4. **Refresh** ボタンを押して最新の履歴を再取得します。最後に更新した時刻が併せて表示されます

## 利用のヒント
:::tip 失敗原因の確認
**Status** が **failed** のジョブは、**Error** カラムでエラーメッセージを確認できます。
:::

:::info 読み取り専用の画面
このページはジョブの実行履歴を照会するだけです。ジョブは他の機能（例: レポート生成）からバックグラウンドで登録され、処理結果がここに表示されます。
:::

:::info 狭い画面
画面が狭くなるとテーブルがカード形式に切り替わり、モバイルでも見やすくなります。
:::
