# ログイン

メールアドレスとパスワードで AWSops にログインできるページです。

<Screenshot src="/screenshots/getting-started/login.png" alt="ログイン画面" />

## 主な機能
### ログインフォーム
- **メールアドレス**: 発行されたメールアドレスを入力します。
- **パスワード**: パスワードを入力します。
- **ログイン状態を保持**: チェックすると、ブラウザを閉じて再度開いてもセッションが維持されます。共用 PC ではオフにしてください。
- **ログイン →**: 入力した認証情報でログインを試みるボタンです。

### 自動リダイレクト
- ログインしていない状態でいずれかのページにアクセスすると、自動的に**ログイン**画面へ移動します。
- ログインに成功すると、ダッシュボード(または元々アクセスしようとしていたページ)へすぐに移動します。

### エラー表示
- 誤ったメールアドレス・パスワード、追加認証が必要なアカウント、一時的なサービスエラーは、フォーム内に**インライン通知**として表示されます。

## 使い方
1. ブラウザで AWSops のアドレスにアクセスします。ログインしていない場合は**ログイン**画面が表示されます。
2. **メールアドレス**と**パスワード**を入力します。
3. セッションを維持したい場合は**ログイン状態を保持**をチェックしたままにします。
4. **ログイン →** ボタンをクリックします。
5. 認証が完了するとダッシュボードへ移動します。
6. ログアウトするには、左サイドバー下部のアカウント名の横にある**ログアウトアイコン**をクリックします。セッションがクリアされ、再び**ログイン**画面に戻ります。

## 利用のヒント
:::tip ログイン状態の保持
**ログイン状態を保持**をチェックすると、次回のアクセス時に再ログインが不要になります。共用・共有デバイスではチェックを外し、使用後は必ずログアウトしてください。
:::

:::info ログインできないとき
フォーム上部にインライン通知が表示されます。メールアドレス・パスワードを再確認し、それでも失敗が続く場合は、しばらくしてから再試行するか管理者にお問い合わせください。
:::
