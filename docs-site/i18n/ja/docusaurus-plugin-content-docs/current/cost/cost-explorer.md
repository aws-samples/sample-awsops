# Cost Explorer

今月の累積コストとサービス別のコスト分布を分析できるページです。

<Screenshot src="/screenshots/cost/cost-explorer.png" alt="Cost Explorer" />

## 主な機能

### 主要指標カード
ページ上部の 5 つの指標カードがコスト状況を要約します:
- **今月の累積**: 今月 1 日から現在までの累積コスト
- **前月比（MoM・日平均）**: 前月比の増減率。今月は進行中のため、**日平均**基準で比較して部分集計による歪みを抑えます
- **月末予想コスト**: AWS の予測値または線形推定値（カード下部に **AWS 予測** / **線形推定** と表示）
- **サービス数**: コストが発生したサービスの数
- **最大サービス**: 最もコストが発生したサービスと金額

### 推移チャート
- **月別コスト推移**: 直近約 6 か月間の月別コストをエリアチャートで表示
- **日別コスト推移**: 直近約 30 日間の日別コストをエリアチャートで表示

### サービス別分布
- **サービス別コスト**: サービスごとのコストを横棒リストで表示
- **コスト構成**: 上位サービスと残りをまとめた**その他**項目をドーナツチャートで表示
- **サービス詳細テーブル**: サービス / コスト / 占有率カラムのソート可能なテーブル

### サービスドリルダウンパネル
テーブルでサービス行をクリックすると、右側に詳細パネルが開きます:
- **日別コスト推移（30 日）**: 該当サービスの直近 30 日間の日別コスト
- **使用タイプの分解**: 直近 3 か月間の使用タイプ（Usage Type）別コスト分解
- パネルの境界をドラッグして幅を調整でき、**×** ボタン・**Esc**・外側エリアのクリックで閉じます

<Screenshot src="/screenshots/cost/cost-drilldown.png" alt="サービスドリルダウンパネル" />

## 使い方

1. サイドバーで**コスト**をクリックします
2. 上部の指標カードで今月の累積コストと月末予想値を確認します
3. 推移チャートで月別・日別のコストの流れを把握します
4. **サービス別コスト**リストと**コスト構成**ドーナツでコスト分布を確認します
5. **サービス詳細**テーブルで行をクリックし、該当サービスの日別推移と使用タイプの分解を確認します
6. 更新ボタンで最新データを再取得します

## 利用のヒント

:::tip 部分集計の理解
今月はまだ進行中のため、**前月比**指標は月全体の合計ではなく**日平均**基準で比較します。そのため、月初・月中でも信頼できる増減率を表示できます。
:::

:::info 部分的な失敗時の動作
推移・月別・予測データの一部を取得できなくても、サービス別分布はそのまま表示されます。コストデータが表示されない場合は、Cost Explorer の権限またはセッション状態を確認してください。
:::

:::info 時刻表記
画面に表示される時刻は韓国標準時（KST, Asia/Seoul）基準です。
:::

## AI 分析のヒント

フローティングボタンの AI Assistant または Assistant ページから、次のように質問できます:
- 「今月コストが最も多いサービスは？」
- 「前月と比べてコストは増えた？減った？」
- 「月末の予想コストを教えて」
- 「EC2 の使用タイプ別コストを分解して」
