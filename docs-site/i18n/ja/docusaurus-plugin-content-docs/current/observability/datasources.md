# データソース探索

接続された可観測性データソースを、それぞれのネイティブクエリ言語で読み取り専用照会できるページです。

<Screenshot src="/screenshots/observability/datasources.png" alt="連携ハブ — データソースタブ" />

## 主な機能

### 対応データソースとクエリ言語
接続されたデータソースを、その種類に応じたネイティブ言語で直接照会します。すべての照会は**読み取り専用**です。

| データソース | クエリ言語 | 例 |
|-----------|----------|------|
| **Prometheus** | **PromQL** | `rate(node_cpu_seconds_total[5m])` |
| **Mimir** | **PromQL** | `up` |
| **Loki** | **LogQL** | `{job="varlogs"} \|= "error"` |
| **Tempo** | **TraceQL** | `{ duration > 500ms }` |
| **ClickHouse** | **SQL** (読み取り専用) | `SHOW TABLES` |
| **Jaeger** | サービス別検索 | `service=frontend&limit=20` |
| **Dynatrace** | Metrics v2 metricSelector | `builtin:host.cpu.usage:avg` |
| **Datadog** | メトリクスクエリ | `avg:system.cpu.user{*}` |

### データソースの選択
- ドロップダウンからデータソースを選びます。各項目には**インスタンス名**と**種類 (kind)** が表示されます。
- AI 生成は別途収集されたスキーマキャッシュを参照します。データソースと種類別デフォルトは共有接続であり、AWS アカウントの選択で範囲は変わりません。
- 接続の設定とテストは管理者のみ実行できます。プライベート接続には運用担当者によるネットワーク・DNS 設定が必要で、設定済みとクエリ検証済みは別の状態です。
- Timeout は Prometheus/Mimir/ClickHouse のサーバー実行上限（既定 10 秒）と他の種類の HTTP 応答上限（既定 12 秒）を区別します。保存値は 1–60 秒で、フォームには実際の最大 55 秒が表示されます。Mimir API 接頭辞の既定は `/prometheus`、ルート API は空欄にします。

### 時間範囲 (range) トグル
- 期間セレクターで **Prometheus/Mimir** は即時または最大 30 日、**Loki** は即時または最大 7 日を選択できます。
- **Tempo/Jaeger** は既定の 1 時間から最大 7 日、**Dynatrace/Datadog** は既定の 1 時間から最大 30 日を照会します。選択期間は実際の検索リクエストに渡されます。
- **ClickHouse** の期間条件は SQL に記述します。AI によるクエリ生成では選択した照会期間は変わりません。

### 結果の表示
- 時系列 (matrix/range) の結果は**時系列エリアチャート**として描画されます。
- 単一時点・ログ・トレース・SQL の結果はソート可能な**テーブル**で表示されます。
- 実際に切り捨てられた結果には**結果が切り捨てられました**という警告が表示されます。検索上限への到達で完全性を確認できない結果は**部分結果**として表示され、確認済みの空の応答には**結果なし**と表示されます。
- 未確認・部分応答からデータが空であるとは判断できません。Jaeger の検索上限に達しても全トレースを取得したことは保証されません。

### AI によるクエリ生成
- 求める内容を自然言語で記述して **AI で生成**を押すと、キャッシュされたスキーマを参照して該当言語のクエリに変換され、入力欄に入力されます。
- 生成されたクエリは**自動では実行されません。** 確認したうえで自ら**実行**を押すことで照会されます。

## 使い方
1. サイドバーの**連携**をクリックし、**データソース**タブで照会するデータソースの **探索 →** を開きます
2. 上部のドロップダウンから照会する**データソース**を選択します
3. (任意) 期間指定に対応するデータソースではセレクターから照会期間を選びます
4. 入力欄に該当言語のクエリを直接入力するか、自然言語で記述して **AI で生成**でクエリを入力します
5. クエリを確認したうえで**実行**(または入力欄で **Enter**)を押して照会します
6. チャートまたはテーブルとして表示された結果を確認します

:::info データソースがないとき
接続されたデータソースがひとつもない場合、ドロップダウンは空になり、**「設定されたデータソースがありません — Datasources タブから追加してください。」**という案内が表示されます。データソースの接続と認証情報の登録は**連携 (Integrations) ハブ**(`/integrations` → データソースタブ)で行います。
:::

:::tip クイック実行
入力欄で **Enter** を押すとすぐに実行されます。自然言語の記述欄で **Enter** を押すと **AI で生成**が実行されます。
:::

:::tip 結果が切り捨てられたら
**結果が切り捨てられました(上限到達)**という警告が表示されたら、クエリの範囲や条件を絞って再度照会してください。
:::

## AI 分析のヒント
- 「直近 5 分間の全ノードの CPU 使用率」 → PromQL クエリとして生成
- 「error を含む最近のログ」 → LogQL クエリとして生成
- 「500ms 以上かかったトレース」 → TraceQL クエリとして生成
- 「テーブルごとの行数」 → 読み取り専用 SQL として生成

## AIで診断

Datasources管理タブでは、各kindの**default**データソース行に**AIで診断**リンクが表示されます
(対応kind: Prometheus・ClickHouse・Loki・Mimir・Tempo)。クリックするとAIアシスタントに移動し、
セクション固定の診断プロンプトが入力欄に事前入力されます(Prometheus/ClickHouse → `/observability`、
Loki/Mimir/Tempo → `/monitoring`)。**自動送信はされません** — 内容を確認して送信すると新しい会話として
開始されます。エージェントは該当コネクタのクエリ/スキーマツールでデータソースの応答状態を確認します。

## Explore 機能まとめ

- kindごとの**サンプルクエリ・自然言語プロンプトチップ**(8 kind)
- **7d/30d 期間プリセット**(Prometheus/Mimir は30d、Lokiは7d — kind別上限)
- 結果**メタデータバー**(行/シリーズ数・往復ms・クエリ言語・形態)
- **Loki専用ログビューア**(新しい順・ラベルバッジ)、Tempo/Jaeger **durationバー**
- AI生成クエリの**出所バナー**、管理タブの**KPIタイル・更新ボタン**
